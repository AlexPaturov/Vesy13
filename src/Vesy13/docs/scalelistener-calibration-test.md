# Проверка калибровки в ScaleListener

## Запуск

1. Запустите `ScaleListener`.
2. В главном окне нажмите `Проверка калибровки`.
3. Оставьте канал `CH0` и стандартные точки:

   | Масса, т | ADC |
   | ---: | ---: |
   | 0 | 10000 |
   | 20 | 20000 |
   | 80 | 40000 |

4. Нажмите `Выполнить тест`. Форма сама создаёт проверки на точках, перед/после точек и внутри интервалов.
5. Сохраните результат кнопкой `Экспорт CSV`, например как `calibration-before.csv`.

## Ожидаемый результат текущей версии

Линейный эталон даёт: 0 т при ADC 10000, 20 т при ADC 20000 и 80 т при ADC 40000. Внутри интервалов ожидаются 5, 10, 15, 35, 50 и 65 т.

В текущей версии нулевая точка включена в первый интерполяционный отрезок. Поэтому для стандартных точек 0 т / 10000, 20 т / 20000 и 80 т / 40000 все проверки должны совпадать с линейным эталоном с точностью до 0.001 т.

Ожидаемый итог: все строки имеют статус `PASS`, отклонений — `0`. При переключении на старый алгоритм ожидаются ошибки на интервале 20–80 т: ADC 25000 → 30 т вместо 35 т, ADC 30000 → 40 т вместо 50 т, ADC 35000 → 50 т вместо 65 т, ADC 39999 → около 60 т вместо 79.997 т.


## Проверка обмена через COM

Для проверки полного пути выберите строку результата, нажмите `Connect`, а в Vesy13 используйте `COM1`. ScaleListener отвечает на запросы по `COM4`; виртуальная пара должна связывать COM1 и COM4. На экране Vesy13 ожидается масса из колонки `ActualMass`. Направочные коэффициенты в этом тесте не участвуют.

После исправления алгоритма с учётом нулевой точки все строки стандартного сценария должны иметь статус `PASS`, а отклонений должно быть 0.
