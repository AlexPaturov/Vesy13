# Отчёт о выполненных работах

Документ ведётся в хронологическом порядке. Новые пункты следует добавлять в конец, сохраняя нумерацию.

## 1. Независимая установка программы и локальной базы данных

- Подготовлены самостоятельные установочные комплекты программы и локальной базы данных.
- Установщик программы выполняет публикацию, установку, создание ярлыка и подготовку каталога рабочих данных.
- Установщик базы данных выполняет установку PostgreSQL, настройку доступа и создание структуры базы данных.

## 2. Журнал изменений калибровки

- В журнал статических калибровочных точек записываются все поля сохранённых изменений.
- В журнал коэффициентов направления записываются данные деактивированного и добавленного профилей.

## 3. Калибровочное число статической точки

- В статической калибровке добавлено отдельное обязательное калибровочное число.
- Расчёт статического веса использует сохранённое калибровочное число.
- На форме статической калибровки добавлен ручной ввод калибровочного числа.
- Калибровочное число включено в журнал изменений статической калибровки.

## 4. Сервисная статическая калибровка

- Ввод массы принимает запятую и точку как десятичный разделитель.
- Ошибочные значения выделяются в таблице и сопровождаются сообщением.
- Кнопка захвата кода АЦП доступна только при живой связи с АЦП и ненулевом коде.
- Из формы удалён блок расчёта методом наименьших квадратов.

## 5. Доработка калибровки, динамического взвешивания:

- Сделал замену динамической калибровки на профиль поправочных коэффициентов правого и левого направлений.
- Сделал расчет динамического веса по выбранной статической калибровочной точке с применением профиля поправочных коэффициентов направлений.
- Результат взвешивания сохраняет идентификаторы статических точек обеих тележек и профиля коэффициентов направления.
- Калибровочное число статической точки переведено в целый тип; 
- Упростил установщик схемы локальной базы, удалил миграции. Теперь база пересоздаётся при каждом запуске установщика.
- Дельта-фильтр динамического потока принимает новый устойчивый уровень после второго подтверждающего сэмпла.
